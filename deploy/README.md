# 部署说明（腾讯云服务器，不影响原有程序）

## 一句话原则
本系统以 **Docker 容器** 方式运行，使用**独立的端口、独立的数据库、独立的网络**，
与服务器上已有程序零耦合。部署 = 一条命令；回滚 = 一条命令。

## 为什么不直接给服务器密码让我登进去搭
1. 本对话环境没有通往你服务器的安全通道，无法（也不应）直接 SSH 登录生产机。
2. 把服务器密码发在对话里既不安全，也没必要——容器化交付比"登进去装软件"更稳、更好回滚。
3. 如果你确实想让我远程操作服务器，正确做法是配置**密钥认证的 SSH 连接器**，而不是在聊天里发密码。

## 部署步骤
1. 在腾讯云服务器安装 Docker 与 Docker Compose（若已安装可跳过）。
2. 把本目录（含 `docker-compose.yml`、`.env`、`Dockerfile`、`package.json`、源码）上传到服务器某一目录，
   例如 `/opt/baodan`。
3. `cd /opt/baodan && cp .env.example .env` 并填好 `JWT_SECRET` 等。
4. 执行 `docker compose up -d`。
5. 应用运行在宿主机 `8080` 端口（Postgres 在 `5433`，Redis 在 `6380`）。
   浏览器访问 `http://<服务器IP>:8080` 即可。

## 端口冲突自检（上线前必做）
在服务器上执行以下命令，确认 8080 / 5433 / 6380 未被占用：
```bash
ss -ltnp | grep -E ':(8080|5433|6380)'
```
若有占用，修改 `docker-compose.yml` 里冒号左侧的宿主机端口即可（容器内侧端口保持不变）。

## 不影响原有程序的保证
- 数据库是独立的 Postgres 容器（不是你现有的 MySQL/MariaDB）。
- Redis 是独立容器，端口 6380，不与现有 6379 冲突。
- 整个系统挂在自有 Docker 网络 `baodan_net` 内，不触碰宿主机其他服务。
- 如需通过 80/443 对外，请在**你现有的 Nginx** 里加一段反代到 `127.0.0.1:8080`，不动原有站点配置。

## 回滚
```bash
cd /opt/baodan && docker compose down   # 立即停止并移除容器，原程序不受影响
```
