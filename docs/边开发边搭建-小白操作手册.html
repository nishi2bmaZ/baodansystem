报单系统·边开发边搭建 操作手册（小白版）

适用对象：完全不懂代码、不懂服务器的新手。 目标：照着做，就能让 WorkBuddy 安全地连上你的腾讯云服务器，实现"边写代码边部署"。 预计耗时：20 分钟（一次性配置，之后就不用管了）。

一、先看这张图，搞懂"我们在连什么"

SSH 加密通道

腾讯云服务器

报单系统 Docker 容器 （我们新建的）

原有程序 照常运行 （完全不动）

↑ 两者互不干扰，独立的端口 / 独立的数据库 / 独立的网络

一句话解释： 你的电脑上跑着 WorkBuddy，它通过一根"加密管道"（SSH）连到腾讯云服务器。在服务器里，我们新建的报单系统和你原来的程序分别住在各自的"集装箱"（Docker 容器）里，互不影响。

二、名词小词典（看不懂就回来查这一节）

词 大白话解释
服务器 / 云主机 一台放在腾讯云上的电脑，7×24 小时开机，跑你的程序
公网 IP 这台云电脑在 internet 上的"门牌号"，形如 129.211.x.x
SSH 一种"安全地远程登录到服务器"的方式，像远程遥控操作那台电脑
连接器 / MCP WorkBuddy 的一个"小插件"，装了它，WorkBuddy 就能用 SSH 连服务器
端口 服务器上不同程序的"门牌号"，比如 22 是 SSH 的门，8080 是我们报单系统的门
Docker 容器 把程序打包成"独立集装箱"，和别的程序隔离开，互不影响

三、开始前，先打勾确认你有以下东西

  • [ ] 一台能上网的 Windows 电脑（就是你装了 WorkBuddy 这台）
  • [ ] 腾讯云服务器的公网 IP（在云控制台能看到，见第四步）
  • [ ] 登录这台服务器的用户名和密码（你平时怎么登，就用什么）
  • [ ] 服务器已经开了 22 端口（SSH，默认一般都开；不确定看第四步）

如果你连"怎么登录服务器"都不知道，没关系，第四步会教你怎么在网页里登录，不用装任何软件。

四、第一步：确认你能登录服务器（最重要，先做）

我们要先拿到三样信息：公网 IP、登录用户名、确认 22 端口开着。

4.1 在网页里登录服务器（最省事，不用装软件）

  1. 打开浏览器，登录 腾讯云控制台。
  2. 左侧点「云服务器」→「实例」，会看到你的服务器列表。
  3. 在列表里找到你的服务器，看这两列： - 公网 IP：记下来（比如 129.211.12.34）← 这就是我们要的 - 状态：必须是「运行中」
  4. 点这一行最右边的「登录」按钮 → 选「标准登录（Linux 实例）」。
  5. 输入你的用户名（一般是 root 或你自定义的名字）和密码，点登录。
  6. 登录成功后，你会看到一个黑色窗口（命令行），光标在闪——这就代表你能控制这台服务器了。

这一步只是为了"确认能登录 + 拿到 IP"。登录进去后不用敲任何命令，直接关掉窗口也行。

4.2 确认 22 端口（SSH）是开的

还是在控制台： 1. 点你的服务器实例名称，进入详情页。 2. 找「安全组」标签 → 点对应的安全组 →「入站规则」。 3. 看有没有一条：协议端口 = SSH(22) 或 TCP:22，来源 0.0.0.0/0 或你的 IP。 4. 如果没有，点「添加规则」，协议选 SSH，端口 22，来源 0.0.0.0/0，保存。

如果 22 是开的（绝大多数默认开），这步跳过。

现在你手上应该有：公网 IP、用户名、密码。 记在记事本里，下一步要用。

五、第二步：在 WorkBuddy 里配置"连接器"（核心动作）

这一步是让 WorkBuddy 能连上服务器。全程在你自己电脑上操作，不需要动服务器。

5.1 找到（或新建）配置文件

  1. 在你电脑上打开「文件资源管理器」。
  2. 地址栏输入（直接复制粘贴）： C:\Users\1\.workbuddy\ 回车。
  3. 在这个文件夹里找一个名为 mcp.json 的文件。 - 如果有：右键 → 用「记事本」打开。 - 如果没有：在空白处右键 → 新建 → 文本文档，改名为 mcp.json（注意：要改掉 .txt 后缀，如果看不到后缀，见下方小提示）。

小提示（看不到文件后缀怎么办）： 文件资源管理器顶部「查看」→ 勾选「文件扩展名」，就能看到并修改 .txt 了。

5.2 把下面这段配置粘进去

用记事本打开 mcp.json 后，把里面原来的内容全部删掉，复制粘贴下面这段：

{
  "mcpServers": {
    "baodan-tencent": {
      "command": "npx",
      "args": [
        "-y",
        "@fangjunjie/ssh-mcp-server",
        "--host", "这里填服务器公网IP",
        "--port", "22",
        "--username", "你的登录用户名",
        "--password", "你的登录密码"
      ]
    }
  }
}

然后，把里面三处中文替换成你自己的真实信息（注意只改引号里面的内容，别删掉引号和逗号）：

位置 改成什么 举例
"这里填服务器公网IP" 你的公网 IP "129.211.12.34"
"你的登录用户名" 你的登录用户名 "root"
"你的登录密码" 你的登录密码 "Abc123456"

改完之后，文件大概长这样（举例）：

{
  "mcpServers": {
    "baodan-tencent": {
      "command": "npx",
      "args": [
        "-y",
        "@fangjunjie/ssh-mcp-server",
        "--host", "129.211.12.34",
        "--port", "22",
        "--username", "root",
        "--password", "Abc123456"
      ]
    }
  }
}

5.3 ⚠️ 三个最容易出错的地方（务必对照检查）

  1. 每个参数和值必须分开写，不能连在一起。 ✅ 正确："--host", "129.211.12.34" ❌ 错误："--host 129.211.12.34"（少了一个逗号分隔，会连不上）
  2. 引号、逗号一个都不能少。 最后一个 ] 和 } 后面没有逗号。
  3. 密码只写在你自己电脑的这个文件里，不要发到我们的聊天里，也不要发给我。

改好后，按 Ctrl+S 保存，关闭记事本。

更安全的做法（可选，不强制）： 如果你担心密码写在文件里，可以改用"密钥登录"，不写密码。但那需要额外生成密钥对并上传，步骤更多。新手先用上面的"密码方式"即可，密码只存在你本地电脑，不会泄露给别人。

六、第三步：让连接器生效（必须点一下"信任"）

光写文件还不够，WorkBuddy 出于安全，需要你手动"信任"这个连接器才会启用。

  1. 打开 WorkBuddy 软件。
  2. 看左侧边栏，找「连接器」（或叫 Connectors / 自定义连接器）入口，点进去。
  3. 在列表里找到刚加的 baodan-tencent（或显示 @fangjunjie/ssh-mcp-server）。
  4. 它旁边应该有个「信任」按钮，点一下信任。
  5. 如果列表里没看到它：完全关闭 WorkBuddy 再重新打开，让它重新读取配置文件。
  6. 信任后，可能需要等几秒，状态变成「已连接 / connected」就成功了。

如果提示"找不到 npx"或启动失败：大概率是没装 Node.js。告诉我，我给你最简安装步骤（装一次就好）。

七、第四步：连通测试（这一步交给我）

连接器信任成功后，你什么都不用做了，把下面三样信息发给我（依然是只发给我看，别发密码到公开聊天）：

  • 服务器公网 IP：__
  • 登录用户名：__
  • 登录密码：__

如果你按第五步已经把密码写进 mcp.json 了，那连 IP 和密码都不用发，直接跟我说一句"测试连接"就行，我直接读配置文件去连。

我会先跑两个无害的测试命令确认通道通了： - ls /opt（看看服务器目录） - docker --version（看看有没有装 Docker）

只有测试通过后，我们才会正式开始部署。 不会一上来就动你的服务器。

八、安心说明：为什么不会搞坏你原来的程序？

这是你最担心的点，我直接说清楚三道保险：

  1. 独立的"门牌号"：报单系统跑在 8080 端口，数据库用 5433，Redis 用 6380，都避开了常见的 80/443/3306/5432/6379。和你原来程序用的端口不冲突。
  2. 独立的"集装箱"：整套系统用 Docker 容器运行，有自己独立的数据库和网络，不碰你服务器上原有的任何程序。
  3. 危险命令被挡住：连接器设了"黑名单"，像 rm -rf、shutdown、reboot、docker system prune 这类会搞破坏的命令，就算误发也会被拦下。
  4. 任何"删除 / 重启"动作，我都会先问你一句，你同意我才做。

如果你哪天不想要了，一条命令 docker compose down 就能把整个报单系统停下并移除，你原来的程序原封不动。

九、常见报错 & 怎么办（遇到对着查）

现象 可能原因 怎么办
连接器启动报错"npx 不是内部命令" 没装 Node.js 告诉我，我给你一键安装步骤
连不上，提示 Permission denied (publickey) 用了密钥方式但公钥没放对 改用"密码方式"（第五步 5.2），或告诉我重做密钥
提示 Connection refused / timeout IP 错、端口不对、或 22 端口没开 回第四步核对 IP 和安全组
命令被执行但提示"被黑名单拦截" 碰到了危险命令 正常保护，告诉我想做什么，我换安全方式
列表里看不到 baodan-tencent 配置文件没保存 / 路径错 确认文件在 C:\Users\1\.workbuddy\mcp.json，关掉 WorkBuddy 重开
